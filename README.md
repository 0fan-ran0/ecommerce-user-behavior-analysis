# 🛒 电商用户行为数据分析
> 数据分析实战项目 | Python + SQL + Pandas + Matplotlib/Seaborn + Streamlit

## 📌 项目简介
基于公开电商用户行为数据集，完成用户浏览、收藏、加购、下单全链路行为分析，挖掘转化漏斗、用户分群、商品热度规律，输出业务建议并搭建交互式可视化看板。
**业务目标：** 定位转化流失节点，对用户做RFM分层，给运营提供决策依据。

## 🧰 技术栈
Python、SQL、Pandas、NumPy、Matplotlib、Seaborn、Streamlit
