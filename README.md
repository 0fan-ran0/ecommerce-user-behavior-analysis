## 📋 数据集说明
数据集来源：阿里天池公开数据集 UserBehavior.csv
> 数据集包含淘宝APP用户行为记录，时间范围：2017-11-25 ~ 2017-12-03
- user_id：用户ID
- item_id：商品ID
- category_id：商品类目ID
- behavior_type：行为类型（pv浏览、cart加购、fav收藏、buy购买）
- timestamp：行为时间戳

⚠️ 注意：原始数据集文件体积巨大，**本仓库不存放原始csv文件**，运行前自行下载放入 `data/raw/`
数据集下载地址：https://tianchi.aliyun.com/dataset/dataDetail?dataId=649

## 🧠 分析思路
1. **数据预处理**：时间戳转日期格式、时间范围过滤、检查缺失值与重复值
2. **探索性分析**：统计各行为数量，计算转化漏斗；分析用户活跃时段分布
3. **RFM用户分层模型**
    - R(Recency)：最近一次购买距离观测结束的天数
    - F(Frequency)：购买次数
    - M(Monetary)：本数据集无消费金额，使用购买次数替代
    - 分层结果：高价值用户、潜力用户、流失高价值用户、新用户、一般流失用户
4. **可视化看板搭建**：Streamlit搭建交互式页面，汇总核心指标、图表、用户查询功能

## 📈 核心结论（面试必背）
1. 用户浏览到购买转化率偏低，大量流量停留在浏览环节，加购/收藏到购买转化有提升空间；
2. 用户活跃存在明显时段规律，晚间是用户访问高峰，可定向在高峰时段投放运营活动；
3. 分层结果中高价值用户占比较少，运营重点一方面召回流失高价值用户，另一方面把潜力用户转化为高价值用户；
4. 大部分用户仅浏览无购买行为，平台需要优化商品推荐、落地页、优惠策略提升转化。

## 📌 面试问答储备（附在 README，自己熟悉）

Q：为什么 RFM 的 M 用购买次数代替？
A：原始数据集没有消费金额字段，无法获取用户消费总额，行业内通用替代方案，同时在报告中注明限制，保证分析客观。

Q：漏斗转化低你怎么理解？
A：电商场景天然存在流量漏斗，浏览基数极大，很多用户只是闲逛、比价；可以从落地页、商品评价、价格优惠、推荐精准度等角度优化转化。
