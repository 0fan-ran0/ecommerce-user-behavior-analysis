# 📊 电商用户行为数据分析项目
> 基于阿里天池公开电商用户行为数据集，完成用户行为漏斗分析、用户活跃特征挖掘、RFM用户分层，配套Streamlit交互式可视化看板。
> 项目方向：数据分析。

2. 针对数据集缺少消费金额字段的限制，采用**购买频次替代M值**，并在文档中明确标注该处理方案，体现数据分析严谨性
3. 构建可部署的Streamlit交互式看板，支持核心指标查看、分层用户筛选，区别于仅输出静态Notebook的项目
4. 代码结构清晰、仓库目录规范化，配套依赖清单，项目具备可复现性

## 📋 数据集说明
数据集来源：阿里天池公开数据集 UserBehavior.csv
> 数据集记录淘宝APP用户行为，时间范围：2017-11-25 ~ 2017-12-03
- user_id：用户ID
- item_id：商品ID
- category_id：商品类目ID
- behavior_type：行为类型（pv浏览、cart加购、fav收藏、buy购买）
- timestamp：行为时间戳

⚠️ 注意：原始数据集文件体积巨大，**本仓库不存放原始csv文件**，运行前自行下载放入 `data/raw/`
数据集下载地址：https://tianchi.aliyun.com/dataset/dataDetail?dataId=649

## 🧠 分析思路
1. **数据预处理**：时间戳转换日期格式、时间范围过滤、缺失值与重复值校验清洗
2. **探索性分析**：统计各类用户行为量级，搭建转化漏斗；挖掘用户活跃时段特征
3. **RFM用户分层模型**
    - R(Recency)：用户最近一次购买距离观测结束的天数
    - F(Frequency)：用户购买次数
    - M(Monetary)：本数据集无消费金额字段，使用购买频次替代
    - 分层标签：高价值用户、潜力用户、流失高价值用户、新用户、一般流失用户
4. **可视化看板搭建**：基于Streamlit开发交互式页面，汇总核心业务指标、可视化图表、用户明细查询功能

## 📈 核心结论
1. 用户从浏览到购买整体转化率偏低，流量大量停留在浏览环节，加购/收藏到下单仍有优化空间；
2. 用户访问存在明显时段特征，晚间为流量高峰，可在该时段定向投放运营活动；
3. 高价值用户占比较低，运营策略分为两条主线：召回流失高价值用户、将潜力用户转化为高价值用户；
4. 平台大量用户仅浏览不下单，可从商品推荐、落地页体验、优惠活动等方向提升下单转化。

## 📌 面试问答储备

Q：为什么 RFM 的 M 用购买次数代替？
A：这份数据集没有消费金额字段，无法统计用户消费总额，这是数据集本身限制。行业内常用购买频次做替代指标，同时在文档里明确标注该局限，保证分析结论客观，不误导业务方。

Q：漏斗转化低你怎么理解？
A：电商天然存在流量衰减漏斗，浏览基数巨大，很多用户只是浏览比价，本身没有强购买意图。想要提升转化，可以从商品推荐精准度、商品评价、价格优惠、落地页体验等角度优化。

Q：漏斗转化低你怎么理解？
A：电商场景天然存在流量漏斗，浏览基数极大，很多用户只是闲逛、比价；可以从落地页、商品评价、价格优惠、推荐精准度等角度优化转化。
